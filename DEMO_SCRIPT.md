# Suggested 4–5 minute demo walkthrough

1. **Create:** use the supplied HTTP Requests and Responses title/objective. Explain that both fields are required.
2. **Research:** show book, website and video result types. Open at least one primary documentation link and explain that the app retains source links/snippets for review.
3. **Generation:** show the 45-minute lesson structure, including explanations, worked examples, practical application and knowledge checks.
4. **QC 1 — research/factual:** explain that this audit looks for unsupported claims, source relevance/reliability, contradictions and evidence gaps.
5. **QC 2 — instructional:** explain that this audit separately checks objective alignment, clarity, sequence, examples, practice and assessment.
6. **Review and edit:** change one section in the editor, save it, then rerun the relevant QC layer.
7. **Export:** download the ZIP and show lesson.md, references.md, qc1_report.json, qc2_report.json and project.json.
8. **Second input:** create SQL Joins: INNER, LEFT and RIGHT and show its independent reports.

If using demo mode, explicitly say it is a structural fallback and not AI-generated or fact-verified content. For the hiring demo, configure an LLM API key and run live research first.
